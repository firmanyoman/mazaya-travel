# Mazaya Travel Rebuild Inventory

Isi paket:

- `mazaya-travel-rebuild-brief.md` — ringkasan fakta, struktur, paket, form, dan rekomendasi rebuild.
- `image-manifest.md` — inventaris gambar yang mudah dibaca.
- `image-manifest.csv` — inventaris gambar untuk spreadsheet/import.
- `image-manifest.json` — inventaris gambar untuk aplikasi atau script.
- `source-pages.md` — daftar halaman sumber.
- `assets/README.md` — catatan hak penggunaan aset.

## Mengapa gambar tidak ikut disalin?

Gambar pada situs menampilkan dokumentasi jemaah dan materi promosi yang dapat dilindungi hak cipta serta hak privasi. Paket ini menyediakan URL sumber dan metadata, tetapi tidak menggandakan file tanpa bukti bahwa pengguna memiliki hak atau izin untuk mengambil dan menggunakannya kembali.
